# Estudio Jurídico Víctor Ibañez

Landing institucional desarrollada con Next.js, TypeScript y Tailwind CSS.

## Ejecutar localmente

1. Instalar Node.js 20 o posterior.
2. En esta carpeta, ejecutar `npm install`.
3. Ejecutar `npm run dev` y abrir `http://localhost:3000`.

## Antes de publicar

- Actualizar los datos de contacto en `app/page.tsx`.
- Reemplazar el enlace de WhatsApp (`wa.me/5493512653082`) por el número real, sin signos ni espacios.
- Configurar el envío real del formulario con un proveedor como Resend, Formspree o una API propia. Actualmente muestra una confirmación local.

Para desplegar en Vercel, importe esta carpeta como un nuevo repositorio o proyecto y use la configuración detectada automáticamente.
